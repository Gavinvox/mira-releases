# Mira — app downloads

Desktop and Android apps for [Mira](https://si.miranex.us). Get the newest files from **[Releases → Latest](https://github.com/Gavinvox/mira-releases/releases/latest)**.

| Platform | File |
|---|---|
| Android | `Mira_X.Y.Z_android-universal.apk` (allow "install unknown apps" for your browser) |
| Linux | `.AppImage` (auto-updates) or `.deb` |
| Mac (Intel, macOS 10.15+) | `Mira_X.Y.Z_x64.dmg` |
| Mac (Apple Silicon or Intel) | `Mira_X.Y.Z_universal.dmg` |

Mac: the app isn't notarized — right-click → Open the first time (or System Settings → Privacy & Security → Open Anyway).

The apps check for updates automatically. This repository contains release files only, no source code.
